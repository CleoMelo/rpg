# Timeline — Cavaleiros Divinos e a Ordem dos Reinos

Importada para `CleoMelo/rpg`.

- `../timeline.html`: editor do mestre (antigo `admin.html`).
- `index.html`: visualização pública original.
- `timeline.json`: conteúdo completo da timeline.
- `timeline-worker/`: Worker usado para leitura, salvamento e backups.

O `workerUrl` fica como `__WORKER_URL__` até um novo Worker ser implantado para este repositório. Isso evita que o editor importado escreva acidentalmente no repositório de origem.
